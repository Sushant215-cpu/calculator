# Calculator

A small, responsive calculator with an everyday unit converter.

## Features

- Basic arithmetic with keyboard support.
- Calculation and conversion history saved in your browser.
- Unit conversions for length, weight, temperature, area, volume, speed, time, and data.
- Responsive layout and reduced-motion support.

## Try it

Open the live calculator at <https://sushant215-cpu.github.io/calculator/>.

To run locally, open `index.html` in a web browser. No dependencies or build step are needed.
